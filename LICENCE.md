## 🧩 About

**Dota 2 catalog Menu** is a curated list of Dota 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD overlay, panel switcher
- **Quality-of-Life Helpers** — item catalog, hero reference, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Panel Switcher — switch between practice panels from any state
- Show Timers — visualize ability and cooldown timers
- Replay Notes — record and review match runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse items, cosmetics, and effects
- Custom Loadout Notes — organize hero loadouts
- Panel Visibility — improved overlay readability

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Camera Control — manually adjust camera mid-match for study
- Input Buffer Notes — chain complex maneuvers in the demo editor
